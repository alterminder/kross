# Frontend

React + TypeScript + Vite. Structure, screens and the trainer view: [docs/architecture/frontend.md](../docs/architecture/frontend.md).

```sh
npm install
npm run dev                         # http://localhost:5173, with the backend dev server on :8765
npm run typecheck && npm test       # Vitest
npm run e2e                         # Playwright against a fresh dev server
```

Running the backend and regenerating the API types: [docs/development.md](../docs/development.md).
