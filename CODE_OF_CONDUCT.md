# Code of conduct

KROSS is built for people who negotiate access for civilians in conflict. We expect the same respect in this
project.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, welcome newcomers, criticise ideas rather than people, and do not harass anyone.

Report unacceptable behaviour privately to the maintainers through a
[private security advisory](https://github.com/alterminder/kross/security/advisories/new) or by contacting a
maintainer directly. Reports are handled confidentially. Maintainers may remove comments, commits or contributions
that break this code, and may ban contributors who repeatedly do.
